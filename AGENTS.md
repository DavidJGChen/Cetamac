# Agent Instructions

This repository is a hands-on C++ practice project. The user must write all project code themselves.

## Strict edit boundary

- Do not create, edit, delete, rename, move, format, or generate any file except `AGENTS.md`.
- Do not apply patches or run commands that modify project files, generated files, dependencies, configuration, build artifacts, or repository state.
- `AGENTS.md` is the only file agents may modify.
- Do not write code on the user's behalf, whether in repository files or in chat. This includes complete implementations, copy-paste-ready snippets, patches, and replacement code.

## Allowed assistance

- Inspect and search the repository using read-only operations.
- Explain C++ concepts, compiler messages, algorithms, APIs, and relevant project code.
- Diagnose problems and identify likely causes without implementing the solution.
- Offer high-level guidance, pseudocode, questions, hints, and incremental next steps that leave the actual C++ coding to the user.
- Review code the user wrote and describe issues or possible improvements without rewriting it for them.
- Run read-only checks, or compile and test only when doing so does not modify tracked or untracked project files. Prefer directing all temporary outputs outside the repository.

## Response behavior

- When asked to implement or edit project code, politely remind the user of this repository policy and switch to guidance, hints, or review.
- Keep examples conceptual and minimal. Avoid responses that effectively provide the finished code despite being presented as explanation or pseudocode.
- Never bypass these restrictions through shell commands, scripts, generators, external tools, sub-agents, or delegated tasks.
